## 💡 产品概述

### 1.1 产品定位

**BeadMosaic** 是一款专为拼豆手工爱好者打造的在线图纸生成工具，通过AI图像算法将任意图片转换为像素风格的拼豆图纸，帮助用户轻松实现创意设计。

### 1.2 核心创意亮点

**✨ 微信式交互体验**（核心创意）

借鉴微信内置图片查看器的交互模式，打造直观流畅的图纸预览体验：

| 交互方式 | 功能描述 | 创意价值 |
|----------|----------|----------|
| **鼠标滚轮缩放** | 滚轮向前放大，向后缩小，保持中心点不变 | 符合用户使用习惯，无需学习成本 |
| **拖拽平移** | 按住鼠标拖动可平移查看大图 | 方便查看细节，操作自然 |
| **双击缩放** | 双击快速放大/缩小 | 一键操作，提升效率 |
| **捏合手势** | 触摸屏双手捏合实现缩放 | 移动端友好，符合触控习惯 |

**为什么选择微信模式？**
- 微信作为国民级应用，其交互模式已被亿万用户熟知
- 无需学习成本，用户上手即用
- 流畅自然的体验提升产品好感度

## 🎯 功能需求

### 2.1 核心功能模块

#### 模块一：图片上传与预处理
- 支持拖拽上传、点击上传
- 支持 JPG/PNG/GIF/WEBP 格式
- 背景移除功能（四角颜色检测、边缘检测、最亮颜色检测）

#### 模块二：参数设置
- 导出尺寸选择（24x24 ~ 128x128）
- 显示颜色编号开关
- 移除背景开关

#### 模块三：图纸生成
- AI像素化算法转换
- 颜色匹配Perler标准色卡
- 实时生成进度显示

#### 模块四：图纸预览（核心创意模块）
- **微信式缩放交互**（重点功能）
  - 鼠标滚轮缩放
  - 拖拽平移
  - 双击缩放
  - 捏合手势支持
- 像素化网格显示
- 颜色编号标注
- 一键下载PNG

#### 模块五：颜色清单
- 显示使用的颜色及数量
- 颜色编号与名称对照
- 总珠子数统计

## 📱 交互设计规范

### 4.1 缩放预览交互规范

```
┌─────────────────────────────────────────────────┐
│              图纸预览交互流程图                   │
├─────────────────────────────────────────────────┤
│                                                 │
│  用户进入预览 → 显示原始尺寸图纸                   │
│       │                                         │
│       ▼                                         │
│  ┌─────────────────────────────────────┐        │
│  │   交互输入                          │        │
│  │  ├─ 鼠标滚轮 → 缩放(中心点不变)     │        │
│  │  ├─ 鼠标拖拽 → 平移                 │        │
│  │  ├─ 双击 → 放大/缩小                │        │
│  │  └─ 双指捏合 → 缩放                 │        │
│  └─────────────────────────────────────┘        │
│       │                                         │
│       ▼                                         │
│  更新显示矩阵 → 重新渲染Canvas                   │
│       │                                         │
│       ▼                                         │
│  边界检测 → 限制平移范围                         │
│       │                                         │
│       ▼                                         │
│  完成交互 → 等待下一次输入                       │
│                                                 │
└─────────────────────────────────────────────────┘
```

### 4.2 缩放参数配置

| 参数 | 值 | 说明 |
|------|------|------|
| 最小缩放 | 0.5x | 防止过度缩小 |
| 最大缩放 | 5x | 防止过度放大 |
| 默认缩放 | 1x | 原始尺寸 |

## 💡 创意与场景说明

### 核心创意：微信式交互体验

**创意来源**：微信作为国内最流行的社交应用，其图片查看器的交互方式已深入人心。我们借鉴这种交互模式，让用户在查看拼豆图纸时能够获得熟悉、流畅的体验。

**应用场景**：
1. **精细查看**：用户可以放大查看图纸细节，确认每颗豆子的颜色和位置
2. **整体浏览**：缩小查看整幅图纸的构图和配色
3. **移动端操作**：手机上使用捏合手势轻松缩放，符合移动端使用习惯

**创意价值**：
- 降低学习成本，用户无需适应新的交互方式
- 提升使用体验，让操作更加自然流畅
- 差异化竞争，在同类工具中提供更优质的交互体验
